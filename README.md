# BSUIR Web Labs

Laboratory works, BSUIR (Belarusian State University of Informatics and Radioelectronics), specialty « Web-design et infographie ».
Travaux de laboratoire, BSUIR, spécialité « Web-design et infographie ».

Each lab is a static website (HTML, CSS, JavaScript) built step by step, from a first page to a full multi-page site. Each folder contains the source code of the site.
