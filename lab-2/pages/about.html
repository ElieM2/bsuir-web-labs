Путь

Меня зовут Eloah Elie Monga Wandala. Я программист, предприниматель, дизайнер и служитель Бога. Учусь в БГУИР по специальности «Веб-дизайн и компьютерная графика», группа 6042244.

Я родился 25 октября в Киншасе, в Демократической Республике Конго. В моей жизни три главные вещи: вера, технологии и творчество.

Я вырос в христианской семье, где к учёбе относились серьёзно. С детства меня учили уважать старших, не сдаваться и держаться веры. Там же появился интерес к творчеству и искусству — потом он постепенно перешёл и в мои проекты.

Сначала вера была «семейной», но в одиннадцать лет мои отношения с Богом стали личными. С тех пор я продолжаю этот путь: узнаю Бога, стараюсь понимать Его Слово и жить по-христиански не только на словах. В четырнадцать лет я решил служить Ему. Молитва не раз помогала мне в моменты, когда помощи от людей было недостаточно, и это только укрепило моё решение. Вера и сейчас остаётся для меня главным ориентиром.

Потом мой путь привёл меня в Минск. Программирование и веб-дизайн — то, чем я занимаюсь в учёбе каждый день. Мне интересно соединять технику, эстетику и идеи: написать программу, придумать интерфейс или собрать визуальный стиль — для меня это разные способы придать форму замыслу.

Мои сильные стороны: упорство, вера и творческий подход.

Скрипт приветствия с главной страницы: выбирает фразу по времени суток.

function greetingPhrase() {
  var hour = new Date().getHours();
  var hello = "Добрый вечер";
  if (hour < 12) {
    hello = "Доброе утро";
  } else if (hour < 18) {
    hello = "Добрый день";
  }
  return hello;
}
